# Interface in java

An Interface in Java is an abstract type that defines a set of methods a class must implement.

An interface acts as a contract that specifies what a class should do, but not how it should do it.

### use case

```
1. When Multiple Classes Need the Same Ability
2. Standard Rules for Different Systems
```

### Default interface

```java
interface Animal {

    void sound();   // abstract method

    default void sleep() {
        System.out.println("Animal is sleeping");
    }
}
// A default method is a method inside an interface that already has implementation (code).
// use case
// If a new method is added to an interface, existing classes won’t break because the interface already provides a default implementation.
// framework update (by adding new features)
class Dog implements Animal {

    public void sound() {
        System.out.println("Dog barks");
    }

}
```

### private method in interface

```java
// Interface can now include private methods.
// Private methods are defined within the interface but it cannot be accessed by the implementing classes.
// Private methods cannot be overridden by implementing classes as they are not inherited.
// private method call by interface only
interface Vehicle {
    // Private method for internal use
    private void startEngine() {
        System.out.println("Engine started.");
    }

    // Default method that uses the private method
    default void drive() {
         // Calls the private method
        startEngine();
        System.out.println("Vehicle is now driving.");
    }
}

class Car implements Vehicle {
    // Car class implements Vehicle interface and inherits the default method 'drive'
}

public class Main {
    public static void main(String[] args) {
        Car car = new Car();
        // This will call the default method, which in turn calls the private method
        car.drive();
    }
}

```

# What is Polymorphism?

The word Polymorphism comes from Greek:  
Poly = Many  
Morphism = Forms  
Polymorphism = One thing (object or method) behaving in many ways.

| Type                      | Description                                                    |
| ------------------------- | -------------------------------------------------------------- |
| **Compile-time / Static** | Method Overloading (same method name, different parameters)    |
| **Run-time / Dynamic**    | Method Overriding (child class changes parent method behavior) |

# encapsulation, and abstraction.

Encapsulation: A capsule → medicine inside is hidden, only outer cover is visible.  
Abstraction: Driving a car → you know how to drive (methods) but don’t care how engine works internally.  
Encapsulation = “Protect the data”  
Abstraction = “Focus on what it does, not how”

```java
// Encapsulation
class Student {

    // Getter
    public String getName() {
        return name;

    // Setter
    public void setName(String name) {
        this.name = name;

    public int getAge() {
        return age;

    public void setAge(int age) {
        if(age > 0)

        s.setAge(20);

        System.out.println("Age: " + s.getAge());
    }
}
```

# What is Constructor Chaining?

Constructor Chaining = Calling one constructor from another constructor  
It allows reusing constructor code  
Helps initialize objects step by step

There are two types:  
Within the same class → Use this()  
Between parent and child class → Use super()

```java
class Student {
    String name;
    int agee;

    // Constructor 1
    Student() {
        this("Unknown", 0);  // calls constructor 2
        System.out.println("No-arg constructor called");
    }

    // Constructor 2
    Student(String name, int age) {
        this.name = name; // this used for set variable name same as the argument name
        agee = age;
        System.out.println("Parameterized constructor called", agee);
    }
}
public class Main {
    public static void main(String[] args) {
        Student s = new Student();
    }
}
```

## chained exceptation with initcase (This method sets the cause for the calling exception.)
```java
public class Main {
    public static void main(String[] args) {
        try {
          
            // Creating an exception
            NumberFormatException ex = new NumberFormatException("Primary Exception");// yaha custom exceptation bhi use kar sakte hai

            // Setting the cause of the exception
            ex.initCause(new NullPointerException("Root cause of the exception"));

            // Throwing the exception with a cause
            throw ex;
        } 
        catch (NumberFormatException ex) {
          
            // Displaying the primary exception
            System.out.println("Caught Exception: " + ex);

            // Displaying the root cause of the exception
            System.out.println("Cause of Exception: " + ex.getCause());
        }
    }
}
```
