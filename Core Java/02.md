# Data Structure
A Data Structure is a way to organize, store, and manage data so it can be used efficiently in a program.  
In simple words:
👉 A data structure decides how data is arranged in memory and how we access or modify it.

# Java Arrays:
Java provides a data structure called the array, which stores a fixed-size sequential collection of elements of the same data type.

# Jagged array 
A jagged array in Java is an array of arrays where each sub-array can have a different length. In simple terms, it’s like a 2D array with rows of unequal lengths.
```JAVA
int[][] jaggedArray; // declaration
jaggedArray = new int[3][]; // 3 rows, columns not defined yet (intialization)
jaggedArray[0] = new int[2]; // row 0 has 2 columns   (intialized all as a specific Column)   
jaggedArray[1] = new int[4]; // row 1 has 4 columns   (intialized all as a specific Column)
jaggedArray[2] = new int[3]; // row 2 has 3 columns   (intialized all as a specific Column)


// Assign the values
jaggedArray[0][0] = 1;
jaggedArray[0][1] = 2;

jaggedArray[1][0] = 3;
jaggedArray[1][1] = 4;
jaggedArray[1][2] = 5;
jaggedArray[1][3] = 6;

jaggedArray[2][0] = 7;
jaggedArray[2][1] = 8;
jaggedArray[2][2] = 9;

// Print 
for(int i = 0; i < jaggedArray.length; i++) {
    for(int j = 0; j < jaggedArray[i].length; j++) {
        System.out.print(jaggedArray[i][j] + " ");
    }
    System.out.println();
}
```

# Strings
**Strings** in Java is an object that represents a sequence of characters.
**Immutable – cannot change once created**

```java
// Syntex 
String s1 = "Hello";
// Stored in the String Pool (special memory area for Strings)

String s3 = new String("Hello");
// Creates a new object in heap memory, not in the String Pool

// Example:
class Main {
	public static void main(String[] args) {
		String s = "Java";
		s = s.concat(" Programming"); // concat return new string and here we reassign 
		System.out.println(s); // Output: Java Programming
	}
}
```

### Some examples:
```java
public class Main {
    public static void main(String[] args) {
        String str = "Hello World";

        System.out.println("Length: " + str.length());          // 11
        System.out.println("Char at 4: " + str.charAt(4));     // o
        System.out.println("Substring: " + str.substring(6));  // World
        System.out.println("Uppercase: " + str.toUpperCase()); // HELLO WORLD
    }
}
```
> # What is the String Pool?  
>Special memory area inside the heap reserved for string literals.  
>Java reuses string objects from the pool to save memory.  
>Only immutable strings (created using literals) go into the pool automatically.  

> # What is string heap?   
>General memory area where all objects are stored in Java.  
>Strings created using `new` keyword go into heap, not the pool (unless explicitly interned).  


```java
// Note: `.intern()` puts a string into the string pool and returns reference from the pool.
String s5 = new String("Java").intern();
String s6 = "Java";

System.out.println(s5 == s6); // true
```

# What are StringBuilder and StringBuffer?  
Both are classes in Java used to create mutable strings, unlike String, which is immutable.  
**StringBuilder** → Introduced in Java 5, non-synchronized → faster.  
**StringBuffer** → Older class, synchronized → thread-safe, slightly slower.

```java
// StringBuilder
StringBuilder sb = new StringBuilder("Hello");

// Append
sb.append(" World");
System.out.println(sb); // Hello World

// Insert
sb.insert(6, "Java ");
System.out.println(sb); // Hello Java World

// Replace
sb.replace(6, 10, "C++");
System.out.println(sb); // Hello C++ World

// Delete
sb.delete(6, 9);
System.out.println(sb); // Hello World

// Reverse
sb.reverse();
System.out.println(sb); // dlroW olleH

// Length and Capacity
System.out.println("Length: " + sb.length());     // 11
System.out.println("Capacity: " + sb.capacity()); // 27 (default + extra)







// StringBuffer

StringBuffer sbf = new StringBuffer("Hello");

// Same methods as StringBuilder
sbf.append(" World");
sbf.insert(6, "Java ");
sbf.replace(6, 10, "C++");
sbf.delete(6, 9);
sbf.reverse();
System.out.println(sbf);

```



# Key Differences Between StringBuilder and StringBuffer
| Feature     | StringBuilder   | StringBuffer                      |
| ----------- | --------------- | --------------------------------- |
| Introduced  | Java 5          | Java 1.0                          |
| Thread-Safe | No              | Yes (synchronized)                |
| Performance | Faster          | Slower (synchronization overhead) |
| Mutability  | Mutable         | Mutable                           |
| Use Case    | Single-threaded | Multi-threaded                    |

# Common Methods (Both Classes)
| Method                     | Description                  |
| -------------------------- | ---------------------------- |
| `append()`                 | Adds string to the end       |
| `insert(index, str)`       | Inserts string at index      |
| `replace(start, end, str)` | Replaces substring           |
| `delete(start, end)`       | Deletes substring            |
| `reverse()`                | Reverses the content         |
| `length()`                 | Returns number of characters |
| `capacity()`               | Returns allocated capacity   |


# When to Use Which  
> **StringBuilder** → When your code is single-threaded, e.g., in local variables, loops, string manipulation.    
> **StringBuffer** → When your code is multi-threaded and multiple threads may access the same string.
